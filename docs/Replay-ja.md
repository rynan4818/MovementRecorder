# MovementRecorder リプレイ（MovementRecorder 0.3.2 / Beat Saber 1.37.4-1.39.1）

記録済みの `.mvrec` を読み込み、ゲームに読み込まれているアバター等をコピーして鑑賞します。セイバーはコピーせず、ゲームが表示している左右のセイバーを記録姿勢で動かします。モデルやトレイルの表示は現在のゲーム・MODに任せ、特定のモデルMODのアセンブリには依存しません。記録ファイルにモデル・テクスチャ・ブレンドシェイプ・当時の譜面設定は含まれないため、元のモデルと当時の設定を用意してください。

1.29.1では開発中の動作確認報告があります。今回の配布版の自動検証と公開前の実機確認状況は、[リリース準備](https://github.com/rynan4818/MovementRecorder/blob/v0.3.2/docs/Replay-Release-Preparation-ja.md)を参照してください。

## 使い方

リプレイ関連のUIは英語表記です。画面のボタン名・設定名は以下の英語表記に対応します。[英語UIの変更対照表](https://github.com/rynan4818/MovementRecorder/blob/v0.3.2/docs/Replay-English-UI-Plan-ja.md) を参照してください。

1. 普段のMODで、記録したときと同じアバターとセイバーを読み込みます。
2. Soloで曲・Standard・難易度を選びます。記録当時の左右設定、部屋調整、譜面オプションも合わせてください。
3. **MOVEMENT RECORDER → Replay** を押してリプレイメニューを開きます。
4. 一覧から記録を選び、必要に応じて「View Settings」を調整し、メニュー内の **Start Replay** を押します。

「Movement Recorder Enabled」は従来どおり記録の設定です。オフでもリプレイを起動できます。ファイル選択そのものでは再生を開始しません。読み込み中はリプレイメニューの「Cancel Load」で中止し、そのまま選び直せます。メニューの戻る操作でも読み込みを中止します。

記録日時・記録秒数・対象数・サイズを1行で表示し、頭の移動距離を右端に表示します。選択した行の情報と距離、上部のファイル名を水色で強調し、「Selected」と表示します。選択ファイル名は鑑賞設定の表示中も確認できます。読込不可の理由は詳細欄で赤色表示します。一覧更新後に選択ファイルが削除・差し替えされていた場合は選択を解除します。[行表示の修正報告](https://github.com/rynan4818/MovementRecorder/blob/v0.3.2/docs/Replay-Menu-Row-Fix-ja.md) を参照してください。

一覧は選択中の譜面に合う記録を新しい順に表示します。対象はゲームの `UserData/MovementRecorder` と、現在選択したカスタム譜面内の `MovementRecorder` フォルダです。ヘッダーを読めないファイルはエラーとして表示します。

「View Settings」で No Fail、コピー元アバターの表示・HMDオフセット適用、鑑賞位置を設定できます。初回の鑑賞位置は後方2mで、調整後は保存したX・Y・Z値を次回起動時にも使用します。再生速度は1.0倍、その他の譜面設定は現在の選択を使います。記録時のスコアを再現する機能ではなく、記録で動かすゲームのセイバーをゲーム自身が判定します。

## コピー元アバターの表示

「View Settings → Show Source Avatar」は初期値OFFです。OFFではコピー元の描画を止め、ONではアバターMOD本来の表示設定に従って表示します。ONにすると、現在のプレイヤーに追従するコピー元と、記録動作を再生する複製を同時に表示できます。

設定は `UserData/MovementRecorder.json` の `showReplaySourceAvatar` に保存され、再生開始時に反映します。変更した値は次回起動時も引き継ぎます。アバターMOD側で非表示の部位を強制的に表示する設定ではありません。セイバーとOtherの表示制御は従来どおりです。

表示ON/OFFにかかわらず、コピー元の表情制御と複製へのBlendShape同期は続けます。元モデルは削除せず、本MODが非表示にしたRendererはリプレイ画面の終了時に元の状態へ戻します。

「Apply HMD Offset to Source Avatar」も初期値OFFです。コピー元表示とこの設定を両方ONにすると、コピー元をHMDと同じX・Y・Z分だけ移動して表示します。例えば前後を−2 mにすると、コピー元もHMDと同じ方向へ2 m移動します。記録動作を再生する複製は記録された位置に表示します。

コピー元が非表示、オフセット適用がOFF、またはX・Y・Zがすべて0の場合は、アバター移動用のオブジェクト生成・描画コールバック登録・毎フレーム処理を省略します。HMDの鑑賞位置と設定値の保存は引き続き利用できます。ON/OFFの変更は次のリプレイ開始時に反映し、再生中に調整したX・Y・Zはその場で反映・保存します。

保存先は同じ `UserData/MovementRecorder.json` です。

| 設定項目 | 初期値 | 内容 |
| --- | --- | --- |
| `offsetReplaySourceAvatarWithHmd` | `false` | コピー元へのHMDオフセット適用 |
| `replayObserverX` | `0` | 左右（−5〜5 m） |
| `replayObserverY` | `0` | 上下（−3〜3 m） |
| `replayObserverZ` | `-2` | 前後（−8〜5 m） |

鑑賞設定と再生中の操作パネルのどちらで変更した値も保存します。アバターのオフセット適用をOFFにしても、位置の設定は保持します。

左右・上下・前後は、両方の画面で0.1 m刻みに調整できます。小数計算の微小誤差を調整時に補正し、XYZを0へ戻したときにはアバター移動の専用処理も解除します。

## 再生中

実際のHMDで見回せます。録画時の頭の姿勢を一人称カメラへ流すことはありません。鑑賞位置は描画カメラとUI用コントローラーに適用し、設定がONの場合はコピー元アバターの表示位置にも適用します。判定用の頭やプレイフィールドは移動しません。実際の手元にセイバーは追加せず、メニュー操作にはUIポインターを使います。

再生中は操作パネルを表示しません。通常のメニューボタンでポーズすると、パネルと、実際の手元に追従する標準のメニュー用コントローラー・ポインターを表示します。「Resume」でパネルと操作用コントローラーを隠して再生を続けます。モデル対応の確認やエラー、再生完了による停止時にも操作できます。

操作パネルには「Resume」「Back to Start」「−5 s」「+5 s」、再生位置スライダー「Playback Position」、鑑賞位置、「Model Mapping」「Back to Song Selection」があります。

シークは同じゲームシーン内で行います。ポーズ中にドラッグして位置を更新し、離した後も停止を維持します。「Resume」で移動先から再生します。スコア・コンボ・エネルギー等はシーク先からの区間として初期化します。曲または記録の末尾で停止した後も、前へ移動して再生できます。

再生が途切れたりモデルが消失した場合は停止します。「Model Mapping」の「Recheck」、または「Back to Song Selection」を使ってください。

## モデルを自動で対応付けできない場合

記録内の検索設定とTransform階層から対応先を探します。同名候補が複数ある場合は勝手に選びません。

- 「Recorded Root」と「Scene Root」を選び、「Save Root Mapping」→「Recheck」で確認します。シーンの識別子には同名オブジェクトを区別する階層番号も表示します。
- 特定の骨等は、「Recorded Object」と「Target Full Path」を指定できます。
- セイバーの固定基準を自動決定できない場合は、左右それぞれの固定されたモデルルートを指定します。動く骨は使えません。
- 不要なルートは省略できます。セイバーの記録は省略できません。
- 途中で消えた記録対象は通常非表示にします。「Keep Missing Objects at Last Pose」も選べます。

対応設定は `UserData/MovementRecorder/Profiles` へ保存します。階層が変わった場合は再確認が必要です。「Reset to Auto」で自動設定へ戻せます。

アバター／Otherのコピー対象はTransform、MeshFilter、MeshRenderer、SkinnedMeshRendererとLODGroupです。スキンの骨・LOD参照を再生側に付け替え、元モデルの表示を終了時に復元します。Animator、IK、DynamicBone等のスクリプトはコピー先で動かしません。未記録の骨・材質アニメーションは再現対象外です。初期スケールを使用し、ChroMapper用の倍率・原点補正は適用しません。

セイバーの階層はコピーと非表示化から除外します。トレイルのリセットや再生成も行わず、標準セイバー・各種セイバーMODの通常の表示処理を維持します。シーク直後の軌跡は各MODの更新に従い、過去の軌跡を厳密に復元する機能はありません。

## レイヤーとカメラ表示

アバターは元モデルのレイヤーを保持し、外部カメラや床ミラーのアバター表示設定に従います。観客用HMDカメラは第三者用のメッシュを表示し、一人称専用のレイヤー6を除外します。レイヤー設定の変更はポーズ・シーク中にも反映します。

Camera2を導入している場合、Camera2のScene設定でREPLAYにカメラを割り当てると、MovementRecorderのリプレイでその設定を利用します。ポーズ・シーク・記録の末尾での停止中もREPLAYを維持し、曲選択へ戻るとメニュー用の設定へ戻ります。

REPLAYに有効なカメラがない場合は、Camera2がPLAY等の次の候補を選びます。FPFCの割り当てや、カスタムシーンを維持する設定はCamera2の選択ルールに従います。

Camera2の一人称カメラへは、現在のHMDの位置・向きを渡します。録画時の一人称視点を復元する機能ではありません。鑑賞位置の移動は専用HMDカメラに適用します。

Camera2は必須ではありません。CameraPlusのみ／カメラMODなしの場合もリプレイ本体を利用できます。Camera2のAPI不足などで連携できない場合は、ゲームログへ理由を一度出してリプレイ本体は続行します。開始時に連携できなかった場合は、Camera2の通常のシーン選択が使われます。

Camera2側のScene設定でREPLAYにカメラを割り当ててください。[連携の仕様と検証記録](https://github.com/rynan4818/MovementRecorder/blob/v0.3.2/docs/Replay-Camera2-Integration-ja.md) を参照してください。

## 表情

通常再生中は、元アバターが現在生成するBlendShapeの表情を鑑賞用モデルへ反映します。CustomAvatarsのAnimatorや、VRM系MODのスクリプト等、表情を生成する方法には依存しません。瞬き、再生中のコンボ等のイベント、現在のキー操作による変化が対象です。記録当時の表情やキー操作はファイルに保存されていないため、その再現ではありません。

ポーズ・シーク・再生完了中は最後の表情を保持し、再開すると元アバターの最新の表情を反映します。元MODの表情制御自体は停止しません。マテリアルの色・テクスチャ切り替えによる表情は同期対象外です。

顔の名前には依存せず、対応したSkinnedMeshRendererのBlendShapeを使用します。元のメッシュが途中で差し替わった場合などは、そのRendererの表情同期を停止してログへ理由を出します。必要な元Animatorの非表示時の更新設定を一時調整し、エラー・再準備・退出時に復元します。MODごとの非表示時の表情更新や実行タイミングは実機での確認が必要です。[表情同期の検証報告](https://github.com/rynan4818/MovementRecorder/blob/v0.3.2/docs/Replay-BlendShape-Live-Fix-ja.md) を参照してください。

## 頭の移動距離とキャッシュ

`Application.persistentDataPath/HMDDistance.litedb` が読めるときだけ「Head Travel (Reference)」を表示します。HeadDistanceTravelled本体の導入は不要です。曲ID・譜面種別・難易度・終了日時が一致する、元DBの過去の値を1桁の小数で表示します。

日時の許容差は±3秒です。候補が複数、別ファイルとの候補重複、日時不明等の場合は空欄です。0mは有効な距離です。DBなし・更新中・破損・未対応形式の場合は距離を省略し、記録ファイルの選択機能は利用できます。

元DBは書き込みません。本体と更新ログを短時間ロックして読み取り専用でメモリへコピーし、独立したLiteDB 5.0.21で読みます。既存DBのアップグレード、再構築、チェックポイントは行いません。

一覧・距離のキャッシュは `UserData/MovementRecorder/Cache` に保存します。「Refresh List」は差分確認、「Rebuild Cache」はヘッダーと距離を再確認します。距離のキャッシュ利用時も元DBの存在・読み取り可否・内容を確認します。キャッシュにリプレイ回数や鑑賞中の距離は記録しません。英語UI版の初回表示時は、保存済みの日本語エラーが残らないよう一覧のヘッダーを再読込してキャッシュを更新します。

## 保存抑止と対応範囲

独自の起動・終了処理とSiraUtilの送信抑止を使い、通常Soloの成績更新を呼びません。再生中のMovementRecorder再記録、BeatLeader／ScoreSaberの記録・保存・送信、対応するSongPlayHistoryのプレイ履歴を抑止します。BeatLeader／ScoreSaberのリプレイと同等のゲーム記録除外を範囲とします。既に読み込まれている対象MODの保存抑止処理を確認できない場合は、理由を表示して開始しません。外部MODのDLLは変更しません。

HeadDistanceTravelled／HDT Counterの生成・表示・計測・保存には介入しません。リプレイ観覧中の距離がHDT側で記録される場合があります。一覧の過去の距離表示は、引き続き既存DBから読み取ります。HDTの有無やバージョンをリプレイ起動条件にはしません。

初期範囲はSolo・Standard・両手セイバー・通常速度です。必須拡張が指定された譜面は開始を止めます。アバター／OtherのMeshRenderer／SkinnedMeshRendererを再生し、これらのコピー対象に付属するTrailRenderer・LineRenderer・ParticleSystemRenderer等の未対応描画は省略します。省略は操作パネルとログに表示します。未対応描画だけで構成されたコピー対象モデルは、対応設定での確認が必要です。セイバーの描画にはこの制限を適用しません。マルチプレイと記録時と異なるモデルへの骨格変換は対象外です。環境演出の乱数は記録ファイルにないため、記録時のランダム演出との一致は保証しません。

`manifest.json` の `gameVersion` は対応開始版の **1.37.4** です。このブランチはBeat Saber 1.37.4-1.39.1向けで、基準ビルドは1.37.4を参照します。
