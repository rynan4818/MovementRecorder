# MovementRecorder リプレイ（Beat Saber 1.29.1 検証版）

記録済みの `.mvrec` を読み込み、ゲームに読み込まれているアバター等をコピーして鑑賞します。セイバーはコピーせず、ゲームが表示している左右のセイバーを記録姿勢で動かします。モデルやトレイルの表示は現在のゲーム・MODに任せ、特定のモデルMODのアセンブリには依存しません。記録ファイルにモデル・テクスチャ・ブレンドシェイプ・当時の譜面設定は含まれないため、元のモデルと当時の設定を用意してください。

ユーザー環境で一覧の表示・選択、曲の開始、アバターとセイバーの再生が確認されています。2026-09-13の表情同期修正はReleaseビルド、内部API照合、自動テストを実施済みで、ユーザーの実機テストでも問題が見られないとの報告を受けています。ポーズ・シークの個別操作、ゲーム終了後の保存先比較については実機確認を継続します。

## 使い方

最新のカメラ複製・レイヤー保持の修正は、自動テストとReleaseビルドに加え、ユーザーからも動作確認OKとの報告を受けています。[検証報告](Replay-Camera-Clone-Layer-Fix-ja.md) を参照してください。

1. 普段のMODで、記録したときと同じアバターとセイバーを読み込みます。
2. Soloで曲・Standard・難易度を選びます。記録当時の左右設定、部屋調整、譜面オプションも合わせてください。
3. **MOVEMENT RECORDER → 記録ファイルを選択** を開きます。
4. 一覧から記録を選び、**この記録を選択** でタブへ戻ります。**リプレイ** を押すと再生を開始します。

「Movement Recorder Enabled」は従来どおり記録の設定です。オフでもリプレイを起動できます。ファイル選択そのものでは再生を開始しません。読み込み中はタブの「読込中止」で中止できます。

一覧は選択中の譜面に合う記録を新しい順に表示します。対象はゲームの `UserData/MovementRecorder` と、現在選択したカスタム譜面内の `MovementRecorder` フォルダです。ヘッダーを読めないファイルはエラーとして表示します。

「鑑賞設定」で No Fail と鑑賞位置を設定できます。初期位置は後方2mです。再生速度は1.0倍、その他の譜面設定は現在の選択を使います。記録時のスコアを再現する機能ではなく、記録で動かすゲームのセイバーをゲーム自身が判定します。

## 再生中

実際のHMDで見回せます。録画時の頭の姿勢を一人称カメラへ流すことはありません。鑑賞位置は描画カメラとUI用コントローラーに適用し、判定用の頭やプレイフィールドは移動しません。実際の手元にセイバーは追加せず、メニュー操作にはUIポインターを使います。

再生中は操作パネルを表示しません。通常のメニューボタンでポーズすると、パネルと、実際の手元に追従する標準のメニュー用コントローラー・ポインターを表示します。「再開」でパネルと操作用コントローラーを隠して再生を続けます。モデル対応の確認やエラー、再生完了による停止時にも操作できます。

操作パネルには、再開、先頭へ、前後5秒、再生位置スライダー、鑑賞位置、モデル対応設定、曲選択へ戻るボタンがあります。

シークは同じゲームシーン内で行います。ポーズ中にドラッグして位置を更新し、離した後も停止を維持します。「再開」で移動先から再生します。スコア・コンボ・エネルギー等はシーク先からの区間として初期化します。曲または記録の末尾で停止した後も、前へ移動して再生できます。

再生が途切れたりモデルが消失した場合は停止します。「モデルの対応設定」の再確認、または「曲選択へ戻る」を使ってください。

## モデルを自動で対応付けできない場合

記録内の検索設定とTransform階層から対応先を探します。同名候補が複数ある場合は勝手に選びません。

- 記録ルートとシーンのルートを選び、「ルート対応を保存」→「再確認」で確認します。シーンの識別子には同名オブジェクトを区別する階層番号も表示します。
- 特定の骨等は、個別の記録対象と対応先パスを指定できます。
- セイバーの固定基準を自動決定できない場合は、左右それぞれの固定されたモデルルートを指定します。動く骨は使えません。
- 不要なルートは省略できます。セイバーの記録は省略できません。
- 途中で消えた記録対象は通常非表示にします。「最後の姿勢で表示」も選べます。

対応設定は `UserData/MovementRecorder/Profiles` へ保存します。階層が変わった場合は再確認が必要です。自動設定へ戻す操作もあります。

アバター／Otherのコピー対象はTransform、MeshFilter、MeshRenderer、SkinnedMeshRendererとLODGroupです。スキンの骨・LOD参照を再生側に付け替え、元モデルの表示を終了時に復元します。Animator、IK、DynamicBone等のスクリプトはコピー先で動かしません。未記録の骨・材質アニメーションは再現対象外です。初期スケールを使用し、ChroMapper用の倍率・原点補正は適用しません。

セイバーの階層はコピーと非表示化から除外します。トレイルのリセットや再生成も行わず、標準セイバー・各種セイバーMODの通常の表示処理を維持します。シーク直後の軌跡は各MODの更新に従い、過去の軌跡を厳密に復元する機能はありません。

## レイヤーとカメラ表示

アバターは元モデルのレイヤーを保持し、外部カメラや床ミラーのアバター表示設定に従います。観客用HMDカメラは第三者用のメッシュを表示し、一人称専用のレイヤー6を除外します。レイヤー設定の変更はポーズ・シーク中にも反映します。

## 表情

通常再生中は、元アバターが現在生成するBlendShapeの表情を鑑賞用モデルへ反映します。CustomAvatarsのAnimatorや、VRM系MODのスクリプト等、表情を生成する方法には依存しません。瞬き、再生中のコンボ等のイベント、現在のキー操作による変化が対象です。記録当時の表情やキー操作はファイルに保存されていないため、その再現ではありません。

ポーズ・シーク・再生完了中は最後の表情を保持し、再開すると元アバターの最新の表情を反映します。元MODの表情制御自体は停止しません。マテリアルの色・テクスチャ切り替えによる表情は同期対象外です。

顔の名前には依存せず、対応したSkinnedMeshRendererのBlendShapeを使用します。元のメッシュが途中で差し替わった場合などは、そのRendererの表情同期を停止してログへ理由を出します。必要な元Animatorの非表示時の更新設定を一時調整し、エラー・再準備・退出時に復元します。MODごとの非表示時の表情更新や実行タイミングは実機での確認が必要です。[表情同期の検証報告](Replay-BlendShape-Live-Fix-ja.md) を参照してください。

## 頭の移動距離とキャッシュ

`Application.persistentDataPath/HMDDistance.litedb` が読めるときだけ「頭の移動距離（参考）」を表示します。HeadDistanceTravelled本体の導入は不要です。曲ID・譜面種別・難易度・終了日時が一致する、元DBの過去の値を1桁の小数で表示します。

日時の許容差は±3秒です。候補が複数、別ファイルとの候補重複、日時不明等の場合は空欄です。0mは有効な距離です。DBなし・更新中・破損・未対応形式の場合は距離を省略し、記録ファイルの選択機能は利用できます。

元DBは書き込みません。本体と更新ログを短時間ロックして読み取り専用でメモリへコピーし、独立したLiteDB 5.0.21で読みます。既存DBのアップグレード、再構築、チェックポイントは行いません。

一覧・距離のキャッシュは `UserData/MovementRecorder/Cache` に保存します。「一覧を更新」は差分確認、「キャッシュ再構築」はヘッダーと距離を再確認します。距離のキャッシュ利用時も元DBの存在・読み取り可否・内容を確認します。キャッシュにリプレイ回数や鑑賞中の距離は記録しません。

## 保存抑止と対応範囲

独自の起動・終了処理とSiraUtilの送信抑止を使い、通常Soloの成績更新を呼びません。再生中のMovementRecorder再記録、BeatLeader／ScoreSaberの記録・保存・送信、対応するSongPlayHistoryのプレイ履歴を抑止します。BeatLeader／ScoreSaberのリプレイと同等のゲーム記録除外を範囲とします。既に読み込まれている対象MODの保存抑止処理を確認できない場合は、理由を表示して開始しません。外部MODのDLLは変更しません。

HeadDistanceTravelled／HDT Counterの生成・表示・計測・保存には介入しません。リプレイ観覧中の距離がHDT側で記録される場合があります。一覧の過去の距離表示は、引き続き既存DBから読み取ります。HDTの有無やバージョンをリプレイ起動条件にはしません。

初期範囲はSolo・Standard・両手セイバー・通常速度です。必須拡張が指定された譜面は開始を止めます。アバター／OtherのMeshRenderer／SkinnedMeshRendererを再生し、これらのコピー対象に付属するTrailRenderer・LineRenderer・ParticleSystemRenderer等の未対応描画は省略します。省略は操作パネルとログに表示します。未対応描画だけで構成されたコピー対象モデルは、対応設定での確認が必要です。セイバーの描画にはこの制限を適用しません。マルチプレイと記録時と異なるモデルへの骨格変換は対象外です。環境演出の乱数は記録ファイルにないため、記録時のランダム演出との一致は保証しません。

`manifest.json` の `gameVersion` は依頼どおり **1.20.0のまま** です。ビルド参照は1.29.1であり、1.20.0での動作確認を意味しません。
