# カメラ複製・レイヤー修正の実装と検証

更新日：2026-09-13。対象：MovementRecorder `BS1.29.1`、変更前HEAD `9dbb5c2`、Beat Saber 1.29.1。

ユーザー指定の [実装計画](Replay-Camera-Clone-Layer-Fix-Plan-ja.md) に従って実装し、自動テスト・Releaseビルド・導入ゲームDLLのAPI照合を完了した。2026-09-13、ユーザーより修正版の動作確認OKとの報告を受けた。

## 変更した動作

- 元HMDカメラを、非アクティブな親の下へ複製する方式に変更した。入力・音声・MODの制御処理と子オブジェクトを有効化前に除去し、Cameraと標準の描画処理を残す。
- 維持する標準描画コンポーネントは `BloomPrePass`、`MainEffectController`、`CameraDepthTextureMode`。元に存在しない描画コンポーネントは追加せず、未知のコンポーネントは除去して型名をログに記録する。
- Bloomの実行時描画データを元カメラから独立させ、複製の終了時に元のRenderTextureを解放しない。ImageEffectのコールバックも複製自身に接続し直す。
- 元カメラのタグ・入力・音声処理を保持する。複製のタグを外し、元HMDカメラの描画だけを止める。実際の頭の追従と鑑賞位置の調整は従来の処理を使用する。
- 元アバターの親・ルート・各子オブジェクトのレイヤーを保持する。再生中は元Rendererのレイヤー変更にも追従し、ポーズ・シーク中も表示設定を反映する。
- 観客用HMDカメラの描画マスクは、元HMDカメラのマスクと複製Rendererの使用レイヤーを合わせ、一人称専用の6を除外する。モデル再準備では追加マスクをリセットする。
- 外部カメラとミラーは、元と同じレイヤーのアバターを既存の表示設定で扱う。Camera2やミラーへの新規パッチは追加していない。

記録形式、BlendShape表情同期、ゲームの実セイバー駆動、HDT計測・保存、ゲーム全体の音声制御は維持した。表情は従来どおり、ポーズ・シーク中には保持する。

## 原因と確認範囲

以前はモデルを複製する際にレイヤー0（Default）へ変更していた。導入済みCustomAvatars 5.3.2は床ミラーにアバター用の3・10を追加するため、0への変更でその設定が効かなくなる。Camera2のアバター表示設定とも対応しなくなる。セイバーは複製・レイヤー変更の対象外であり、アバターだけ表示されないという報告と整合する。

元のレイヤーを保持する修正を完了し、ユーザーより修正版の動作確認OKとの報告を受けた。床ミラーの最終マスクや描画方式を実行中のゲームから取得する調査は行っていない。
