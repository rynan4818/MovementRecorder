# コピー元アバターの表示設定とリプレイメニュー整理：設計計画書

作成日：2026-09-13。対象：MovementRecorder `BS1.29.1`、変更前HEAD `5f8cec7`。

状態：ユーザーのOKを受けて実装。検証結果は [実装・検証報告](Replay-Menu-Source-Visibility-ja.md) に記載する。

## 画面と操作

### MOVEMENT RECORDERタブ

- リプレイ機能の入口を「リプレイ」ボタン1個にまとめる。現在の「記録ファイルを選択」の位置に配置し、押すとリプレイメニューを開く。
- タブにある選択ファイル名、リプレイ状況、直接再生するボタン、読込中止ボタンはリプレイメニューへ集約する。
- 記録の有効化、記録対象、記録フレームレートなどの既存設定は引き続きタブで操作する。

### リプレイメニュー

- 現在の記録ファイル選択画面を「MovementRecorder リプレイ」に変更する。
- 操作は「一覧から記録を選択 → 必要に応じて鑑賞設定を変更 → リプレイ開始」とする。現在の「この記録を選択」でタブへ戻る手順を廃止する。
- 選択中のファイル名、記録の情報、読込状況、リプレイ開始、読込中止をこの画面にまとめる。ファイル名は鑑賞設定を開いている間も確認できるようにする。
- 読込中は選択変更・一覧更新・設定変更・再生の連打を止め、「読込中止」を操作できる状態にする。中止してもメニューを開いたままにして、同じ記録を再び再生できるようにする。
- 戻る操作では読込を中止して曲選択へ戻る。読み込み失敗はメニュー内に表示する。
- 未選択、読込不可、対象譜面が未確定の状態では再生を無効にする。

### 選択状態の表示

- 選択行の記録情報と、選択中ファイル名を水色で強調し、「選択中」の文字も付ける。色だけに依存しない表示にする。
- 未選択は通常色、読込不可の理由はエラー表示として区別する。フルパスは既存の「詳細」で確認できるようにする。
- 一覧の再読込、スクロール、鑑賞設定との切替、メニューの再表示でも、同じ有効なファイルの選択と強調表示を維持する。
- 譜面が変わった場合や、選択ファイルが削除・差し替えされた場合は選択を解除する。別ファイルを自動で選択して再生することはない。
- ファイル名等の文字列は表示用の色指定と分けて扱い、名前に含まれる記号で文字装飾が変わらないようにする。

## コピー元アバターの表示設定

- リプレイメニュー内の「鑑賞設定」に「コピー元アバターを表示」を追加する。
- 初期値はOFFとし、従来どおりコピー元を非表示にする。設定は既存の設定ファイルへ `showReplaySourceAvatar` として保存し、次回起動時も引き継ぐ。
- ONでは、コピー元を本MODで強制的に隠さず、アバターMOD本来の表示設定・レイヤーに従って表示する。現在のプレイヤーに追従するコピー元と、記録動作を再生する複製モデルを同時に表示できる。
- OFFでは、現在と同様にコピー元Rendererの描画を止める。オブジェクト自体は残し、表情制御と複製へのBlendShape同期を続ける。
- 表示・非表示の対象は記録種別が `Avatar` の対応元モデルとする。名前や特定のアバターMODには依存せず、実セイバーと `Other` の表示制御は既存の扱いを維持する。
- 表示設定は再生開始時にセッションへ取り込み、その再生とモデルの再準備に使用する。再生中の一時停止画面への切替項目追加は今回の操作範囲に含めない。
- 表示ONでは元の描画フラグへ介入しない。非表示にするRendererのみ変更前の値を保存し、終了・再準備・生成失敗時に復元する。コピー元の消失検出は表示設定によらず維持する。

## 現在の実装から変更する点

- `SettingTabViewController.*`：ファイル情報・再生・中止のバインディングを整理し、メニューを開くボタンにする。
- `ReplayFileViewController.*`：開始・中止・表示設定・選択強調を追加する。画面内に収まるよう情報欄と鑑賞設定の高さを調整する。
- `ReplayMenuService.cs`：候補と確定済みファイルの二段階選択を、メニュー内の選択に統一する。現在はメニュー表示中に `CanReplay` がfalseになるため、メニュー内から開始できる状態判定に変更する。
- `ReplayFileFlowCoordinator.cs`：読込中はメニューを表示し、準備完了後に画面を閉じる。閉じる処理の完了後に譜面と読込世代を再検証し、曲の開始へ進む。戻る操作による中止と、正常な再生開始のための画面終了を区別する。
- 現在の譜面取得はアクティブな曲詳細画面を対象としている。メニュー表示中は開始時に確定した譜面情報を使用し、曲詳細画面が再表示された後に一致を確認する。
- 非同期の一覧更新・読込完了・画面終了コールバックが遅れても、中止後に再生したり、古い選択を復活させたりしないようにする。
- `PluginConfig.cs`、`ReplaySession.cs`、`PlaybackRuntime.cs`：設定の保存と再生セッションへの受け渡しを追加する。
- `ModelBinding.cs`、`RenderModelClone.cs`：対応済みトラックの種別と階層からコピー元アバターの範囲を特定し、対象Rendererごとに非表示の要否を判断する。
