- Support for Beat Saber 1.40.0-1.40.8
- Beat Saber内で記録済みのアバター・セイバー等を鑑賞するリプレイ機能を追加
- リプレイのファイル選択、一時停止・シーク、英語UI、頭の移動距離の参考表示に対応
- アバターの表情同期、元レイヤーの保持、Camera2のREPLAYシーン連携に対応
- コピー元アバターの表示・HMDオフセット適用のON/OFF、0.1m単位の位置調整と設定保存を追加

リプレイはSolo / Standard / 両手セイバーが対象です。記録したときと同じモデルと譜面設定を用意して下さい。記録当時の表情は保存されていないため、再生中の元アバターの表情を反映します。

設定ファイルと既存の記録ファイルはそのまま利用できます。Camera2 / CameraPlusは必須ではありません。

**Beat Saberのバージョンに合わせて使用して下さい。**

- 1.29.0-1.29.1 → [Release v0.3.0](https://github.com/rynan4818/MovementRecorder/releases/tag/v0.3.0)
- 1.37.1-1.39.1 → [Release v0.3.1](https://github.com/rynan4818/MovementRecorder/releases/tag/v0.3.1)
- 1.40.0-1.40.8 → [Release v0.3.2](https://github.com/rynan4818/MovementRecorder/releases/tag/v0.3.2)
- 1.42.0-1.44.1 → [Release v0.3.3](https://github.com/rynan4818/MovementRecorder/releases/tag/v0.3.3)

**1.44.2以降は未対応です。上記以外のバージョンには、対応する従来版の記録機能を使用して下さい。**

使い方は[README](https://github.com/rynan4818/MovementRecorder/tree/BS1.40.0)と[リプレイの使い方](https://github.com/rynan4818/MovementRecorder/blob/v0.3.2/docs/Replay-ja.md)を参照して下さい。
